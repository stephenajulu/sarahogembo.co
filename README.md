## ✦ Brand Positioning & Creative Philosophy

This platform is intentionally engineered to elevate perception—blending **luxury hospitality (Four Seasons standard)**, **executive leadership**, and **international keynote speaking (Bloomberg Live / TED)**. 

It rejects generic event-vendor tropes, decorative clutter, and stock imagery in favor of:
- **Restraint & Editorial Whitespace**: Large sections, generous breathing room, and intentional layout rhythm.
- **Jewellery-like Gold Accents**: Metallic and champagne gold used as deliberate highlights rather than paint.
- **Authentic Stage Photography**: 100% real event and editorial photography of Sarah commanding stages, moderating plenaries, and engaging audiences.
- **Executive Voice**: Grounded, conversational, confident prose that communicates poise and trust to C-suite decision-makers.

   - *Corporate Conferences & Seminars* (Engaging. Polished. Impactful.)
   - *Executive Summits & Moderation* (Focused. Engaging. Insightful.)

7. **Signature Trio**:
   - **Card A (The Difference)**: Gold parchment card with headline *“It’s Not Just What I Say, It’s How I Make People Feel”* and an 8-point verified checklist.

9. **Beyond The Stage (Personal Brand)**: Reflection on human connection, mentorship, and communication, anchored by Sarah's core leadership pillars.

## ✦ CloudCannon CMS (Zero Code Required)

The entire website is configured for **CloudCannon CMS**, allowing the site owner to manage every aspect of the site without touching code:

- **Visual On-Screen Editing**: With `data-cms-bind` attributes, the owner can click directly on text or images on the rendered page to edit.
- **Sidebar Form Cards**: Repeatable cards with drag-and-drop reordering, deletion, and "+ Add Item" buttons for **Services**, **Testimonials**, **Stats**, **Gallery Photos**, and **Client Logos**.
- **Global Settings Data (`data/settings.yml`)**: Update phone numbers, WhatsApp links, official emails, social media handles, and footer quotes in one place.
- **One-Click Blog Publishing (`archetypes/article.md`)**: A rich-text WYSIWYG editor for publishing new articles.
- **User Guide Included**: Comprehensive instructions are provided in [CLOUDCANNON_GUIDE.md](CLOUDCANNON_GUIDE.md).

## ✦ Technical Standards

- **Static Site Generator**: GoHugo v0.160.1 Extended (builds 29 pages in under **200ms**).
- **Accessibility**: Strict **WCAG 2.1 AA** compliance:
  - Contrast ratio >= 4.5:1 (Gold on Black achieves **9.3:1**; Dark text on Ivory achieves **16.5:1**).
  - Visible focus rings (`:focus-visible` with gold glow).
  - Accessible Skip-to-Content anchor (`.skip-to-content`).
  - Semantic HTML5 landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
  - Minimum touch targets >= 44px × 44px.
  - Native `prefers-reduced-motion` support.
- **Performance**:
  - Pure vanilla JavaScript ([static/js/main.js](static/js/main.js)) — zero heavy dependencies.
  - Responsive WebP images with JPEG fallbacks, explicit dimensions, and native lazy-loading (0 CLS).
- **SEO & Structured Data**:
  - OpenGraph and Twitter Cards metadata.
  - Schema.org JSON-LD `Person` (JobTitle: Corporate Master of Ceremonies) and `WebSite` graph.
  - Auto-generated `sitemap.xml` and `robots.txt`.
- **Progressive Web App (PWA)**:
  - `manifest.webmanifest` and service worker (`sw.js`) for offline caching and fast return visits.
  - Complete icon suite (192px, 512px, Apple touch icon, and modern SVG favicon).

## ✦ Getting Started Locally

### Prerequisites
- [Hugo Extended](https://gohugo.io/installation/) (v0.160.0 or later)
- Git

### Run Development Server
```powershell
# Clone the repository
git clone https://github.com/stephenajulu/sarahogembo.co.git
cd sarahogembo.co

# Start local server with draft rendering
hugo server -D
```

Open `http://localhost:1313` in your browser.

### Build for Production
```powershell
hugo --minify
```
The compiled, production-ready static site will be generated in the `public/` directory.

## ✦ Deployment

This site is 100% static and zero-configuration ready for deployment on:

- **CloudCannon**: Connect repo, set SSG to Hugo, build output `public`.
- **Cloudflare Pages**: Connect GitHub repo, build command `hugo`, output directory `public`.
- **Netlify**: Connect repo, build command `hugo --gc --minify`, publish directory `public`.
- **GitHub Pages**: Deploy directly via GitHub Actions using the official Hugo action.
